GPU Ray Tracer

Building a GPU path tracer using the Vulkan compute pipeline (no ray tracing extensions). It renders a static image and is mainly a base for my bachelor’s thesis.

The focus is on implementing and comparing different acceleration structures (e.g. BVH, KD-Tree) and seeing how they behave in terms of performance and memory on the GPU.
